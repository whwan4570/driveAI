# Status 3D model

`modern-sedan.glb` is a CC0 generic executive sedan from [3DAssets.dev](https://3dassets.dev/assets/transport-collection-hd-executive-sedan-cfa7dfcf). It is a visual placeholder for the Status screen's 360° viewer and is recolored to the saved exterior color. It is not a model-specific scan or an exact 2014 Hyundai Sonata model.

`demo.glb` was supplied by the project owner as a SAM 3D-derived model for the Carmori demo Sonata. The Status screen uses it for the 2014 Hyundai Sonata instead of the earlier `sonata.glb` asset. The source image and generation manifest are not in this repository, so this bundled asset is distinct from the proposed automatic per-vehicle SAM 3D pipeline.
