# Status 3D model

`modern-sedan.glb` is a CC0 generic executive sedan from [3DAssets.dev](https://3dassets.dev/assets/transport-collection-hd-executive-sedan-cfa7dfcf). It is a visual placeholder for the Status screen's 360° viewer and is recolored to the saved exterior color. It is not a model-specific scan or an exact 2014 Hyundai Sonata model.
