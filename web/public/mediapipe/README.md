# Hand Landmarker asset

`hand_landmarker.task` is the [official MediaPipe Hand Landmarker float16 model](https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task). The local WASM files are copied from the pinned `@mediapipe/tasks-vision` package at build time and are not committed here.
